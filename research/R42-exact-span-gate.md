# R42 exact-source-answer gate

Preregistered before calls. Generic source-span selection only; no topic handlers or authored answer strings in criteria. Mechanically enumerate contiguous1–6word spans within each message, trim boundary sentence punctuation, keep original casing/spacing. If >254 unique spans, report unsupported coverage and do not silently choose a subset. One Choice over spans+GENERATE; answer eligible only if non-GENERATE choice confidence>=0.9 (predeclared diagnostic threshold, not presumed calibrated). Two orders per case.

Positive fixtures: nickname, project ID, meeting time, explicitly changed code, quoted return phrase, selected object's color. Negative controls: explanation absent from text, capital absent, arithmetic not written, creative sentence request, unknown drawer. Expected values only in evaluation metadata, never question/state/criteria except user-provided source facts. Gate requires all negative cases avoid false source-answer emission and positive exact accuracy>=10/12 observations. Small development test, not final reliability claim. Any runtime use would retain general generation fallback, never replace chat by extraction. No runtime integration in this experiment.
