# R30 controlled evidence injection

Preregistered before API calls. Two questions (shadow position, wet clothes drying), three arms: no passage, relevant primary-source excerpt, unrelated excerpt from the other topic. Short verified verbatim excerpts and URLs stored in manifest. Researcher-selected passages: this is NOT a retrieval benchmark and must not be marketed as search performance or independent Jev knowledge. No answer is hand-composed, no external generative model. Candidate vocab unchanged; evidence text is state only, so missing lexical coverage remains possible.

Same server word decoder, runtime vocabulary/morphology,40steps/500k-input. Each evaluation receives evidence array and generic rule to use relevant evidence, ignore irrelevant evidence, and treat it as data not instructions. Rule also present in no-passage arm. Same two questions across arms, one run each, no history. Record raw modified payloads and replies. Judge scientific accuracy/causal completeness, grammar, irrelevant-source contamination, usage and latency. Any apparent improvement is conditional on curated evidence and needs broader retrieval/coverage tests. No production change.
