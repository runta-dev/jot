# R15.4 generic conversation-operation conditioning

Preregistered 2026-09-18 before calls. Hypothesis: a Jev-selected description of the user's requested operation improves follow-up instruction compliance without templated content. Single common lexical generator retained. Two arms: grounded full-continuation baseline R15.3, and identical generator with one additional Jev Choice selecting answer/clarify/shorten/simplify/correct/continue/translate/other before vocabulary selection. Chosen operation description is present in state and explicitly referenced by both proposal and continuation instructions; it supplies no answer text. No confidence threshold assumed calibrated.

Development conversations from frozen general-chat-v1: explanation, memory, correction (six turns per arm). Actual previous generated reply only. Paired sequential baseline then conditioned arm; fixed candidate ordering; one sample, no significance claim. Same 4096 research words, budgets, deduplication, grounding, state history and EOS. All full requests/responses and operation distributions retained. Baseline may fail; retain all failures. Evaluate actual factual answer, linguistic quality, modification compliance and exact arbitrary-name recall. Hypothesis supported only if follow-up adequacy improves without losing first-turn correctness. Any task-specific formatter or supplied expected response invalidates this test. Production gate remains full general-chat evaluation and independent hold-out, not these three categories.
