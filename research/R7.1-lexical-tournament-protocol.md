# R7.1 — no early group pruning

Preregistered after R7 results. Keep the exact same cases, vocabularies, roles and two orderings. Replace only candidate search: evaluate every <=112-word group independently, keep its top two words, then one final Choice compares all group winners. Questions for separate groups run in parallel within batches of at most 24. No gold terms enter any request.

This removes the first group's top-two pruning gate at increased input cost. It does not guarantee the correct term survives within-group selection. Report full coverage, finalist coverage, final decision, literal outputs, requests and token costs. Compare against R7, preserving the originally declared illustrative expected sets; qualitatively valid alternatives such as prioritize are identified separately, not retroactively added to exact-match scores.

This is still only concept retrieval. A concept pair is not a complete factual explanation or a valid chat reply. Passing permits a later composition test, not deployment.

Attribution reminder: R7's role descriptions were manually authored per topic. They do not contain answer words, but they do supply a decomposition (for example asking for a physical property). A deployable next experiment must use identical generic role prompts or have Jev select the role itself; it cannot silently retain human planning for each new chat question.
