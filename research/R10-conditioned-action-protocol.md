# R10 — predicate first, then conditioned arguments

Preregistered before inference. Motivated by R8's independent topical words and R9's failure to cross a verb/object change together. Frame-semantic literature distinguishes predicates and the roles they license; we borrow that principle, not a pretrained semantic parser.

All eight prompts use identical role instructions. Three development questions concern procrastination, reading retention and deadlines; five fresh probes concern a large project, vocabulary, desk clutter, distractions and starting a first draft. No expected verb/noun/adjective or answer sentence is supplied.

Pipeline: select an implementable first action (verb) that is a means rather than a restatement of the desired outcome; select a general valency frame and linker using Jev; select its concrete argument conditional on that verb/frame; select an optional property of that argument (not a property of the answer's writing style). Generic word tournaments use the unchanged research lexicons. Source spans or it can fill a primary patient in a resultative frame. Realize generic intransitive, direct-object, prepositional, or object-plus-preposition clauses with jsRealB. Compare grammatical variants. These are grammar productions, not intent-specific response sentences.

This tests one-step advice only and does not replace the open-ended goal. Gate for further testing: >=6/8 concrete useful actions, >=4/5 fresh probes, no harmful or contradictory advice. Tautologies and generic use a technique outputs fail. Record all costs; no deployment based on this single small set.
