# R15: restore end-to-end general-chat evaluation

Preregistered 2026-09-18 before new measurements. Development set: evaluations/general-chat-v1.json, eight two-turn conversations. These cases are development, not held-out. Future integration requires fresh untouched conversations, independently assessed. No templates or evaluator reference answers are sent to Jev. Actual generated assistant answers, including bad ones, become subsequent-turn history; never substitute a reference answer.

Baseline: current server/jev.ts question, parseChoice, repetition guard and EOS. At most 280 characters per turn, 180 seconds per turn; record full exact requests/responses, version, attempts, token usage, elapsed and first-character latency. Interrupted/empty replies are failures, not excluded observations. Limit initial run to first two conversations to diagnose instrumentation and failure; do not extrapolate four turns to eight conversations. No API changes or live UI integration in this experiment.

Primary outcome: human inspection for task correctness, coherent English, contextual follow-up, instruction compliance, completeness. Report each dimension separately; protocol end (EOS) does not imply task completion. Latency/cost only compared for equally adequate replies. Later candidate gate: at least 14/16 adequate development turns, no fabricated unknown answer, no repetition/empty failures, then fresh hold-out evaluation. This small gate is necessary, not sufficient for general capability.

External replication candidate: Code-Forge-AU/jev-llm, discovered through author's public 2026-09-18 post. Grouped vocabulary proposals then rendered-continuation reranking, optional speculative fan-out. Hypothesis: contextual reranking improves multi-turn fluency over plain word or character choice. Risks: fixed vocabulary, pruning by incomparable group probabilities, repeated-prefix drift, cost. Review source/provenance/license before copying code; independently implement algorithm if no license. Author's performance claims are unverified. Do not promote their demo into evidence.
