# R15.2 fixed-candidate factorial diagnostic

Preregistered before requests, 2026-09-18. Replay every recorded R15.1 reranking state (identity and explanation, including actual generated history). Four conditions: original full-continuation criteria; appended fragment only; each with/without a generic grounding instruction. Preserve the exact same candidate IDs, EOS, original state and candidate coverage. Deduplicate identical rendered text across candidate IDs in all four conditions, retaining first ID, to avoid capitalized/lowercase duplicate vote splitting. This is a disclosed change from R15.1, so compare paired conditions here, not old probabilities directly.

Grounding instruction: 'Avoid universal capability claims or promises unsupported by state. Prefer a concrete useful answer; acknowledge uncertainty or limitations when relevant.' It contains no reference answer or task-specific phrase. Fragment arm strips the exact already-produced prefix from option descriptions; both arms see full prefix in state. Evaluate four conditions together per state, sequential states, no retries of wrong answers. Two passes: normal and reversed candidate order. This is a conditional decision experiment, not end-to-end generation or a production gate.

Measure selected continuation, EOS disagreements, ordering stability and provider input/output usage. Critical failure state is 'I can help with'; check whether grounding moves away from unsupported 'anything/everything'. Do not infer unseen future reply quality or claim global improvement from an individual better choice. After analysis choose a single preregistered end-to-end method for R15 development, then held-out validation if eligible.
