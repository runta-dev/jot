## Rubric assessment

Full: identity adequate; capability statement is grammatical and concrete but programming competence is not established by this experiment, so treat capability truth as unverified rather than pass. Evaporation explanation adequate. Simplification fails the requested transformation: it repeats the original simple statement and adds “Heat helps.” More content is not evidence of simplification. Thus two clear passes, one unverified, one failure.

Fragment: identity adequate. Capability response is ungrammatical and vague. Explanation contains the right physical idea but “gas into air from clothes” is awkward. Follow-up rearranges the same words, without a meaningful simplification. One clear pass, one borderline factual explanation, two failures.

Full rendered continuation is the better current research default for grammatical composition, but the small nonrandom time-ordered trial does not prove robust superiority. EOS in all cases is transport/termination success, not useful completion. Both arms ignore the specific requested transformation on follow-up. The frozen evaluator must not label this “context success” just because evaporation is mentioned twice.

## Next falsifiable hypothesis

The composition judgment optimizes locally plausible continuation but lacks an explicit representation of the current conversational request. A generic Jev decision identifying the requested operation (answer, clarify, shorten, simplify, correct, continue, translate, other) could condition every proposal/rerank without supplying answer text. This is a generic generation control, not a specialized response handler: all content still follows the same lexical decoder. Test paired existing method versus operation-conditioned method on fresh development transformations, retaining actual previous replies and no reference text. Keep action uncertainty and selection error visible; do not replace the answer with templates. This remains a hypothesis, not an implemented fix.
