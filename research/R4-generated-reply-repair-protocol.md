# R4 — edit actual failed Jev generations

Preregistered before execution. Freeze R3.2's top-two-action editor, extracted into a reusable module without changing its proposal constructor or selection rules.

Apply it to all six archived R2.1 word replies and six archived R2 character replies. These drafts were generated by Jev, not written as near-correct examples. Include the already-correct single-word answers. Empty drafts remain failures and are not replaced with a template.

State supplies the original user request and assistant identity facts (Jev, TypeSafe), but no reference reply. Up to three editing iterations; terminate when unchanged or when a previous draft recurs. Log every intermediate draft, proposal and request. The editor's input instruction asks for the smallest correction satisfying the request without unsupported information.

Human-readable evaluation uses R2's frozen criteria. Distinguish grammar repair from actually answering the prompt. No deployment gate is inferred from success on a few repairable greetings. This test asks whether editing can bridge the generation gap, not whether we can create a perfect hand-written draft.
